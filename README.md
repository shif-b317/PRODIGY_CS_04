# PRODIGY_CS_04 - Simple Keylogger Simulator

## Description
This project is a simple educational keylogger simulator developed using Python and Tkinter. The program records keystrokes typed inside the application window and stores them in a text file.

## Features
- Records keyboard inputs
- Saves keystrokes to a log file
- Handles special keys like:
  - Space
  - Enter
  - Backspace
  - Arrow keys
- Simple graphical user interface using Tkinter
- Timestamp support

## Technologies Used
- Python
- Tkinter
